ОБОЧИНА

Зона не злая. Зона просто устроена не по-человечьи. Ты — сталкер: выйди, найди, вернись, продай. Не геройствуй.

WASD / стрелки — движение
Shift — бег · Ctrl / C — красться
Мышь — направление
ЛКМ — применить выбранное (пистолет / болт / …)
ПКМ (держать) — осмотреться у курсора
E / F — взаимодействие
1–5 / Q / колесо — быстрый выбор
Tab / I — инвентарь, навыки
M — карта
Esc — закрыть окно

Совет: бросай болты перед собой. Слушай Зону. Возвращайся до выброса.
